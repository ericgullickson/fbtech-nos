fbtech-nos apt repository

Signed apt repository of fbtech-nos overlay packages for Debian trixie.

Add it with:

curl -fsSL https://ericgullickson.github.io/fbtech-nos/fbtech-nos-archive-keyring.asc | sudo tee /usr/share/keyrings/fbtech-nos-archive-keyring.asc >/dev/null
echo "deb [signed-by=/usr/share/keyrings/fbtech-nos-archive-keyring.asc] https://ericgullickson.github.io/fbtech-nos trixie main" | sudo tee /etc/apt/sources.list.d/fbtech-nos.list
sudo apt-get update
